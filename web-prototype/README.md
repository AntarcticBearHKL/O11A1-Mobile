# O11A1 Mobile · Web Prototype V2

一个纯 HTML / CSS / JS 的手机端布局与手感原型。**所有内容都是占位块，视频区域不加载任何媒体。**

V2 目标：极简扁平、每页一个主逻辑、没有底部工具栏、视频流占满窗口、右滑打开侧边栏、首页无应用栏（状态栏下玻璃渐变）、一行一个视频、搜索为主界面右下角浮动玻璃按钮、底部不显示播放列表、无 Toast、无旧版灰色提示条、播放器横屏；播放器分三区手势，中间下滑收起、上滑出工具栏、左右竖滑亮度/音量、左滑全屏评论、双击左右旋转、长按左右变速；主页面也支持横屏。

> Android APK 直接以本目录为 UI 源：Gradle 构建时复制 `index.html` / `app.js` / `native.js` / `styles.css` 到 `assets/web`。`native.js` 只在 `window.O11A1Native` 桥存在时启用；浏览器里保持纯占位原型。

## 打开

直接双击 `index.html`，或者：

```powershell
cd web-prototype
python -m http.server 4173
```

然后打开 http://localhost:4173

也可以双击 `start.cmd`（启动本地服务器并打开浏览器）。

清空原型状态：打开 http://localhost:4173/?reset=1，或在右下角 `PROTO` → `重置原型状态`。

## 原型里能做什么

### 根导航

- **没有底部工具栏**：视频流占满整个窗口；在屏幕上向右滑，从左边展开侧边栏。
- **强制登录**：未登录冷启动直接停在登录 gate，首页 / 侧边栏 / 搜索 / 播放器 / 播放列表全部不可达；登录页只有一个透明描边按钮，点击打开 B 站官方登录页，登录成功后同步 Cookie；退出登录同时清理原生 Cookie 和 WebView Cookie；二维码登录代码和页面已删除，只保留官方网页登录。
- 侧边栏包含全部入口：首页 / 收藏 / 直播 / 关注 / 动态 / 消息 / 历史 / 我的；不再有搜索按钮；不再有 5 个自选槽位或全量预览编辑器。
- 养鱼（AI 看片）默认隐藏：侧边栏、我的、主页模块都不显示；我的 → 防干扰 → 隐藏养鱼入口 可恢复。
- 首页「推荐」读取 B 站首页推荐流，不固定为热门；每次重新加载使用新的 fresh 批次并去重，同一个列表里不会重复出现同一条视频。首页/搜索/模块视频流使用 10 条一块的滑窗：最多保留 3 块真实内容，焦点进入第 3 块时卸载最旧一块并补下一块，保持当前可见行位置，同时清空旧块缓存；不再有下拉刷新。
- 左侧菜单滑出时，主页面 3D 缩放后移并投影，形成前后层次。
- 首页没有顶栏：状态栏下只有玻璃渐变；没有品牌、头像、刷新、chips、标题；右下角常驻浮动搜索按钮。
- 搜索只保留从右侧滑入的全屏面板：主页面后退，顶部只有占满宽度的搜索框和放大图标，没有返回箭头；键盘覆盖面板，不把页面顶起；右滑关闭时面板向右滑出、主页面推回。
- 桌面暖纸背景完整继承：暖纸底 + 左上古桃光晕 + 右上冷蓝光晕 + 下方薄荷光晕 + 3px 点阵；壁纸固定在 App 壳上。
- 所有页面都没有标题栏：首页和子页都只在状态栏下有玻璃渐变；内容直接开始，滚动时从渐变下面经过。
- 一行一个视频：封面高度撑满 100px 行高，左/上/下无内边距，右侧渐变淡出到信息区；标题 + UP/发布时间/热度胶囊。
- 模块切换只显示「主页模块」里启用的模块；入口是「我的 → 主页模块」。
- 播放列表不在底部：视频流和所有页面一直铺到屏幕底边；视频行左滑加入播放列表；完整播放列表页从右下角悬浮列表按钮、侧边栏「播放列表」或播放器设置进入，支持下滑关闭；右下角是搜索与播放列表两个浮动按钮。
- 横屏主页：设备横过来（或 PROTO → 横屏主页）切到横屏布局；内容 860 居中、视频行封面 206×112 并保留右侧渐变；侧边栏仍从左滑出。

### 页面

- 首页视频行点击 → 直接进入空横屏播放器并开始播放；收起后回到视频流，播放状态保留在播放列表，没有中间详情页。
- 搜索：右侧滑入全屏面板；热门 / 联想 / 结果同页；右滑反向退出；没有返回箭头和独立结果页。
- 播放器：标题 / 播放列表 / 更多；左滑全屏评论；收藏、投币、加入播放列表都在「更多」sheet。
- 播放列表页：从右下角列表按钮、侧边栏或播放器设置进入；两位队列序号 + 卡片式 row、当前项、左滑删除、长按排序、清空、空状态；顶部抓手可下滑关闭；不是 sheet。
- 动态 / 消息：筛选胶囊、扁平列表。
- 我的：从左侧滑入的覆盖层，主界面后退并缩放；底部固定账号信息抽屉（头像 / 昵称 / UID / 等级 / 粉丝 / 账户按钮），一级菜单只保留主页模块和全部设置项（播放 / 弹幕 / 外观 / 手势 / 防干扰 / 账户 / 快捷键 / 系统 / 屏蔽 / 智能云屏蔽 / 存储 / 优化 / 关于）；养鱼默认隐藏。
- 登录：强制全屏登录 gate；未登录不渲染首页；登录页只有一个透明描边按钮，打开 B 站官方登录页，登录成功后同步 Cookie；我的 → 账户 → 退出登录回 gate。
- 设置已并入「我的」一级菜单，不再有独立设置页；条目见上。
- 主页模块：12 个模块开关，分首页 / 内容 / 社区三组。
- 模块页：收藏 / 历史 / 番剧 / 直播 / 分区 / 关注 / 养鱼 / 会员等统一壳。

### 播放器

- 全屏横屏空播放器；顶部返回 / 标题 / 播放列表 / 更多；底部浮起工具栏：播放 / 上一个 / 下一个 / 时间 / 音量静音+滑杆 / 全屏；弹幕开关 + 输入 + 发送；画质 / 倍速 / 插帧 / 增强 / 循环 / 播放列表 / 面板 / 设置 / 截图。
- 画面分左 / 中 / 右三区：
  - 中间下滑 → 收起播放器；音频/进度/列表继续，播放状态保留在播放列表页。
  - 中间上滑 → 滑出播放器工具栏，重置 3 秒自动隐藏。
  - 工具栏空白/拖拽条向下滑 → 隐藏工具栏和顶部栏。
  - 左侧竖滑 → 亮度；右侧竖滑 → 音量；对应竖向 HUD（桌面滚轮音量条同款）。
  - 左滑 → 全屏评论；面板跟手进入，右滑/返回关闭。
  - 双击左 / 右 → 旋转到横屏·左 / 横屏·右；不再触发 ±10s。
  - 长按左 → 0.5× 慢放；长按右 → 2.0× 快放；松开恢复。
  - 双击中间 → 播放 / 暂停；单击显隐控件。
- 播放器工具栏复刻桌面：播放/上一个/下一个/时间/音量/全屏 + 弹幕输入 + 画质/倍速/插帧/增强/循环/播放列表/面板/设置/截图。
- 播放器面板 sheet 复刻桌面侧栏：信息 / 选集 / 评论 / 性能 / 设置。
- 控件 3 秒自动隐藏；锁定后只留解锁胶囊。
- 全屏评论：暖纸全屏、顶部返回 + 条数、最热/最新、评论列表、底部输入 + 发送；发送就地插入并短暂显示「已发送」。
- 画质 / 倍速 / 插帧 / 增强 / 弹幕设置 sheet。
- 播放列表页：队列序号、当前项、切换、左滑删除、长按排序、清空；空列表显示空状态。
- 更多 sheet：播放设置、弹幕设置、循环模式、播放器比例、锁定、截图、收藏、复制链接。
- 播放设置 sheet 内可直接改画质、插帧、增强、4K、仅音频。

### PROTO 抽屉

右下角 `PROTO` 打开，不属于 App：

- `iOS / Android`：只切换玻璃材质，布局和尺寸完全不变。
- `占位标签`：隐藏所有占位标签，只看布局。
- `8px 网格`：显示基线。
- `背景纹理`：在桌面同款暖纸/光晕/点阵和纯平背景之间切换。
- `动效`：模拟“减少动态效果”。
- `横屏播放器`：直接打开空播放器。
- `横屏主页`：在 920×470 的横屏壳里预览主页；再点一次恢复竖屏。
- `PAGES`：快速跳页。
- `TOKENS`：当前布局 token；`PLAYER GESTURES` 列出手势映射。
- `重置原型状态`：清空 localStorage。

### 手势 / 视觉自查

- `?selftest=1`：自动跑亮度、音量、中间收起、全屏评论、发送、双击旋转、长按变速，结果显示在浏览器标签标题（`SELFTEST ...`）。
- `?demo=volume` / `brightness` / `rate` / `rotate`：打开播放器并保持对应 HUD。
- `?demo=comments`：打开全屏评论。
- `?demo=landscape`：直接进入横屏主页。
- `?nomotion=1`：关闭过渡，方便截图。

## 状态

- 模块开关、播放列表、当前项、播放器设置、亮度/音量、横屏主页开关会写入 `localStorage`，刷新后保留。
- `?reset=1` 或 PROTO 抽屉里的重置按钮可恢复默认。
- 所有反馈都是内联状态：收藏变「已收藏」、加入队列变「已加入」、清空需二次点击；没有 Toast。

## 文件

- `index.html`：结构

- `app.js`：页面切换、模块、播放列表、视频搜索、播放器、sheet、手势、PROTO 抽屉

## 注意

- 没有真实视频、没有真实 B 站接口、没有真实账号。
- 这是用来规划布局和手感的，不是最终播放器。
- iOS 玻璃 / Android 磨砂在原型里用 CSS 近似；真机实现见 `MOBILE_DESIGN.md` 第 7 节。
