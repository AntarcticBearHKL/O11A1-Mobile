# O11A1 Mobile · Web Prototype V2

一个纯 HTML / CSS / JS 的手机端布局与手感原型。**所有内容都是占位块，视频区域不加载任何媒体。**

V2 目标：极简扁平、每页一个主逻辑、没有底部工具栏、视频流占满窗口、右滑打开侧边栏、首页无应用栏（状态栏下玻璃渐变）、一行一个视频、搜索在侧边栏底部、播放列表为视频流底部浮动框、无 Toast、无旧版灰色提示条、播放器横屏；播放器分三区手势，中间下滑收起、上滑出工具栏、左右竖滑亮度/音量、左滑全屏评论、双击左右旋转、长按左右变速；主页面也支持横屏。

> Android APK 直接以本目录为 UI 源：Gradle 构建时复制 `index.html` / `app.js` / `native.js` / `styles.css` 到 `assets/web`。`native.js` 只在 `window.O11A1Native` 桥存在时启用；浏览器里保持纯占位原型。

## 打开

直接双击 `index.html`，或者：

```powershell
cd web-prototype
python -m http.server 4173
```

然后打开 http://localhost:4173

也可以双击 `start.cmd`（启动本地服务器并打开浏览器）。

清空原型状态：打开 http://localhost:4173/?reset=1，或在右下角 `PROTO` → `重置原型状态`。

## 原型里能做什么

### 根导航

- **没有底部工具栏**：视频流占满整个窗口；在屏幕上向右滑，从左边展开侧边栏。
- **强制登录**：未登录冷启动直接停在登录 gate，首页 / 侧边栏 / 搜索 / 播放器 / 播放列表全部不可达；点二维码或「模拟登录」进入首页，登录态保存；设置 → 账户可退出。
- 侧边栏包含全部入口：首页 / 收藏 / 直播 / 关注 / 动态 / 消息 / 历史 / 我的；最底部是独立搜索动作按钮；不再有 5 个自选槽位或全量预览编辑器。
- 养鱼（AI 看片）默认隐藏：侧边栏、我的、主页模块都不显示；设置 → 防干扰 → 隐藏养鱼入口 可恢复。
- 首页/搜索/模块视频流使用触底无限加载：每次追加一段，只保留最近两段，旧段自动丢弃；不再有下拉刷新。
- 左侧菜单滑出时，主页面 3D 缩放后移并投影，形成前后层次。
- 首页没有顶栏：状态栏下只有玻璃渐变；没有品牌、头像、刷新、chips、标题、搜索。
- 搜索在侧边栏最底部、是独立动作按钮：点它进入全屏视频搜索，搜索页顶部只有一个搜索框；取消恢复原页；清除 ×。
- 桌面暖纸背景完整继承：暖纸底 + 左上古桃光晕 + 右上冷蓝光晕 + 下方薄荷光晕 + 3px 点阵；壁纸固定在 App 壳上。
- 所有页面都没有标题栏：首页和子页都只在状态栏下有玻璃渐变；内容直接开始，滚动时从渐变下面经过。
- 一行一个视频：150×84 封面 + 标题 2 行 + UP/时间；整体行高加大。
- 模块切换只显示「主页模块」里启用的模块；入口是「我的 → 当前模块」，或设置 → 主页模块。
- 播放列表不在侧边栏：非空时在视频流底部显示浮动圆角框；视频行左滑加入；上滑展开当前播放；点击进入完整播放列表页；空列表隐藏；没有底部播放行。
- 横屏主页：设备横过来（或 PROTO → 横屏主页）切到横屏布局；内容 860 居中、视频行封面 206×116；侧边栏仍从左滑出。

### 页面

- 首页视频行点击 → 直接进入空横屏播放器并开始播放；收起后视频流底部出现浮动播放列表框，没有中间详情页。
- 搜索：侧边栏底部搜索按钮进入搜索页，顶部只有一个搜索框；全屏「搜索视频」+ 热门视频；输入后视频结果；没有命令列表。
- 播放器：标题 / 播放列表 / 更多；左滑全屏评论；收藏、投币、缓存、加入播放列表都在「更多」sheet。
- 播放列表页：浮动框点击进入；当前项、移除、清空、空状态；不是 sheet。
- 动态 / 消息：筛选胶囊、扁平列表。
- 我的：账号卡 + 收藏/历史/关注/离线缓存/大会员/当前模块/主页模块/设置；养鱼默认隐藏；播放列表不在这里，用视频流底部浮动框。
- 登录：强制全屏 QR gate；未登录不渲染首页；点二维码或「模拟登录」进入首页并保存登录态；设置 → 账户 → 退出登录回 gate。
- 设置：播放 / 弹幕 / 离线下载 / 外观 / 手势 / 底部导航 / 防干扰 / 主页模块 / 账户 / 快捷键 / 系统 / 屏蔽 / 智能云屏蔽 / 存储 / 优化 / 关于。
- 主页模块：12 个模块开关，分首页 / 内容 / 社区三组。
- 模块页：收藏 / 历史 / 番剧 / 直播 / 分区 / 关注 / 养鱼 / 下载 / 会员等统一壳。

### 播放器

- 全屏横屏空播放器；顶部返回 / 标题 / 播放列表 / 更多；底部浮起工具栏：播放 / 上一个 / 下一个 / 时间 / 音量静音+滑杆 / 全屏；弹幕开关 + 输入 + 发送；画质 / 倍速 / 插帧 / 增强 / 循环 / 播放列表 / 面板 / 设置 / 截图。
- 画面分左 / 中 / 右三区：
  - 中间下滑 → 收起播放器；音频/进度/列表继续，底部浮动播放列表框弹入/更新。
  - 中间上滑 → 滑出播放器工具栏，重置 3 秒自动隐藏。
  - 工具栏空白/拖拽条向下滑 → 隐藏工具栏和顶部栏。
  - 左侧竖滑 → 亮度；右侧竖滑 → 音量；对应竖向 HUD（桌面滚轮音量条同款）。
  - 左滑 → 全屏评论；面板跟手进入，右滑/返回关闭。
  - 双击左 / 右 → 旋转到横屏·左 / 横屏·右；不再触发 ±10s。
  - 长按左 → 0.5× 慢放；长按右 → 2.0× 快放；松开恢复。
  - 双击中间 → 播放 / 暂停；单击显隐控件。
- 播放器工具栏复刻桌面：播放/上一个/下一个/时间/音量/全屏 + 弹幕输入 + 画质/倍速/插帧/增强/循环/播放列表/面板/设置/截图。
- 播放器面板 sheet 复刻桌面侧栏：信息 / 选集 / 评论 / 性能 / 设置。
- 控件 3 秒自动隐藏；锁定后只留解锁胶囊。
- 全屏评论：暖纸全屏、顶部返回 + 条数、最热/最新、评论列表、底部输入 + 发送；发送就地插入并短暂显示「已发送」。
- 画质 / 倍速 / 插帧 / 增强 / 弹幕设置 sheet。
- 播放列表页：当前项、切换、移除、清空；空列表隐藏浮动框。
- 更多 sheet：播放设置、弹幕设置、循环模式、播放器比例、锁定、截图、收藏、复制链接。
- 播放设置 sheet 内可直接改画质、插帧、增强、4K、仅音频。

### PROTO 抽屉

右下角 `PROTO` 打开，不属于 App：

- `iOS / Android`：只切换玻璃材质，布局和尺寸完全不变。
- `占位标签`：隐藏所有占位标签，只看布局。
- `8px 网格`：显示基线。
- `背景纹理`：在桌面同款暖纸/光晕/点阵和纯平背景之间切换。
- `动效`：模拟“减少动态效果”。
- `横屏播放器`：直接打开空播放器。
- `横屏主页`：在 920×470 的横屏壳里预览主页；再点一次恢复竖屏。
- `PAGES`：快速跳页。
- `TOKENS`：当前布局 token；`PLAYER GESTURES` 列出手势映射。
- `重置原型状态`：清空 localStorage。

### 手势 / 视觉自查

- `?selftest=1`：自动跑亮度、音量、中间收起、全屏评论、发送、双击旋转、长按变速，结果显示在浏览器标签标题（`SELFTEST ...`）。
- `?demo=volume` / `brightness` / `rate` / `rotate`：打开播放器并保持对应 HUD。
- `?demo=comments`：打开全屏评论。
- `?demo=landscape`：直接进入横屏主页。
- `?nomotion=1`：关闭过渡，方便截图。

## 状态

- 模块开关、播放列表、当前项、播放器设置、亮度/音量、横屏主页开关会写入 `localStorage`，刷新后保留。
- `?reset=1` 或 PROTO 抽屉里的重置按钮可恢复默认。
- 所有反馈都是内联状态：收藏变「已收藏」、加入队列变「已加入」、清空需二次点击；没有 Toast。

## 文件

- `index.html`：结构
- `styles.css`：布局 / 材质 / 动效
- `app.js`：页面切换、模块、播放列表、视频搜索、播放器、sheet、手势、PROTO 抽屉
- `start.cmd`：本地服务器 + 打开浏览器

## 注意

- 没有真实视频、没有真实 B 站接口、没有真实账号。
- 这是用来规划布局和手感的，不是最终播放器。
- iOS 玻璃 / Android 磨砂在原型里用 CSS 近似；真机实现见 `MOBILE_DESIGN.md` 第 7 节。
