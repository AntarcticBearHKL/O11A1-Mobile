# O11A1 Mobile · Web Prototype

一个纯 HTML / CSS / JS 的手机端布局与手感原型。**所有内容都是占位块，视频区域不加载任何媒体。**

## 打开

直接双击 `index.html`，或者：

```powershell
cd web-prototype
python -m http.server 4173
```

然后打开 http://localhost:4173

也可以双击 `start.cmd`（会启动本地服务器并打开浏览器）。

## 原型里能做什么

- 4 个根 tab：首页 / 动态 / 消息 / 我的
- 首页 2 列占位卡片、搜索页、详情页、评论占位
- 点击卡片进入详情；点击视频占位进入**横屏空播放器**
- 播放器：控件自动隐藏、双击左/右 ±10s、锁定、画质/倍速/插帧/增强 sheet、右侧信息/选集/评论/设置栏
- 顶部工具栏：
  - `iOS / Android`：只切换玻璃材质，布局和尺寸完全不变
  - `占位标签`：隐藏所有占位标签，只看布局
  - `网格`：显示 8px 基线
  - `动效`：模拟“减少动态效果”
  - `横屏播放`：打开空播放器
- 右侧 SPEC 面板：布局 token、页面跳转、当前平台

## 文件

- `index.html`：结构
- `styles.css`：布局 / 材质 / 动效
- `app.js`：页面切换、播放器、sheet、手势、工具栏

## 注意

- 没有真实视频、没有真实 B 站接口、没有真实账号。
- 这是用来规划布局和手感的，不是最终播放器。
- 下一步：把占位组件替换成真实组件，接入 Rust core + 原生播放器。
