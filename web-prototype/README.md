# O11A1 Mobile · Web Prototype V2

一个纯 HTML / CSS / JS 的手机端布局与手感原型。**所有内容都是占位块，视频区域不加载任何媒体。**

V2 目标：极简扁平、每页一个主逻辑、顶部只留模块标题 + 搜索、一行一个视频、播放列表一等入口、无 Toast、无 mini-player、播放器横屏。

## 打开

直接双击 `index.html`，或者：

```powershell
cd web-prototype
python -m http.server 4173
```

然后打开 http://localhost:4173

也可以双击 `start.cmd`（启动本地服务器并打开浏览器）。

清空原型状态：打开 http://localhost:4173/?reset=1，或在右下角 `PROTO` → `重置原型状态`。

## 原型里能做什么

### 根导航

- 最终 5 个槽位：首页 / 动态 / 播放列表 / 消息 / 我的。
- 评审默认「全量预览」：桌面端 10 个底栏按钮（首页 / 收藏 / 搜索 / 养鱼 / 直播 / 关注 / 动态 / 消息 / 历史 / 刷新）+ 播放列表 + 我的 = 12 个，两行 6+6 玻璃 dock。
- 设置 → 底部导航：关掉全量预览后只显示勾选的 5 个；最多 5、至少 1；选择顺序就是底部顺序。
- 首页顶部只有 `模块标题 ⌄` 和搜索；没有品牌、头像、刷新、chips。
- 桌面暖纸背景完整继承：暖纸底 + 左上古桃光晕 + 右上冷蓝光晕 + 下方薄荷光晕 + 3px 点阵；壁纸固定在 App 壳上。
- 顶部栏使用玻璃条：半透明暖纸 + 背景模糊 + 1px 发丝线；页面内容从下方滚过时模糊。
- 一行一个视频：142×80 封面 + 标题 2 行 + UP/时间。
- 模块切换菜单只显示「主页模块」里启用的模块。
- 播放列表替代 mini-player：当前项、播放中标签、移除、两步清空、数量 badge。
- 搜索是命令面板：搜索 + 快速命令 + 页面跳转 + 切换模块。

### 页面

- 首页 → 详情 → 空横屏播放器。
- 详情：16:9 占位、标题、UP、关注、播放、评论/简介/相关 tab、相关推荐。
- 播放列表：队列、当前项、清空、空状态。
- 动态 / 消息：筛选胶囊、扁平列表。
- 我的：账号卡 + 播放列表/收藏/历史/关注/养鱼/离线缓存/大会员/主页模块/设置。
- 登录：全屏 QR 占位；点二维码模拟登录成功；可刷新二维码。
- 设置：播放 / 弹幕 / 离线下载 / 外观 / 手势 / 底部导航 / 防干扰 / 主页模块 / 账户 / 快捷键 / 系统 / 屏蔽 / 智能云屏蔽 / 存储 / 优化 / 关于。
- 主页模块：12 个模块开关，分首页 / 内容 / 社区三组。
- 模块页：收藏 / 历史 / 番剧 / 直播 / 分区 / 关注 / 养鱼 / 下载 / 会员等统一壳。

### 播放器

- 全屏横屏空播放器；顶部返回 / 标题 / 队列 / 更多；底部播放 / 时间 / 画质 / 倍速 / 插帧 / 增强 / 弹幕 / 全屏。
- 没有右侧栏；信息、选集、评论、性能、设置、队列全部进 sheet。
- 控件 3 秒自动隐藏；单击显隐；双击左右 ±10s；锁定后只留解锁胶囊。
- 画质 / 倍速 / 插帧 / 增强 / 弹幕设置 sheet。
- 队列 sheet：切换当前、打开播放列表页。
- 更多 sheet：播放设置、弹幕设置、循环模式、播放器比例、锁定、截图、收藏、复制链接。
- 播放设置 sheet 内可直接改画质、插帧、增强、4K、仅音频。

### PROTO 抽屉

右下角 `PROTO` 打开，不属于 App：

- `iOS / Android`：只切换玻璃材质，布局和尺寸完全不变。
- `占位标签`：隐藏所有占位标签，只看布局。
- `8px 网格`：显示基线。
- `背景纹理`：在桌面同款暖纸/光晕/点阵和纯平背景之间切换。
- `动效`：模拟“减少动态效果”。
- `横屏播放器`：直接打开空播放器。
- `PAGES`：快速跳页。
- `TOKENS`：当前布局 token。
- `重置原型状态`：清空 localStorage。

## 状态

- 模块开关、播放列表、当前项、播放器设置会写入 `localStorage`，刷新后保留。
- `?reset=1` 或 PROTO 抽屉里的重置按钮可恢复默认。
- 所有反馈都是内联状态：收藏变「已收藏」、加入队列变「已加入」、清空需二次点击；没有 Toast。

## 文件

- `index.html`：结构
- `styles.css`：布局 / 材质 / 动效
- `app.js`：页面切换、模块、播放列表、命令面板、播放器、sheet、手势、PROTO 抽屉
- `start.cmd`：本地服务器 + 打开浏览器

## 注意

- 没有真实视频、没有真实 B 站接口、没有真实账号。
- 这是用来规划布局和手感的，不是最终播放器。
- iOS 玻璃 / Android 磨砂在原型里用 CSS 近似；真机实现见 `MOBILE_DESIGN.md` 第 7 节。
